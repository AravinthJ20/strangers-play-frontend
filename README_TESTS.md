# Frontend Test Cases

These tests validate the homepage components and login form behavior.

## Test cases

1. Landing page render
   - Renders the hero headline
   - Renders "Create Your Account" CTA
   - Renders "I already have an account" link

2. Login form error handling
   - When login API rejects, show "Login Failed" message

## Run locally

```bash
cd green-lynk-frontend
npm install
npm test
```
